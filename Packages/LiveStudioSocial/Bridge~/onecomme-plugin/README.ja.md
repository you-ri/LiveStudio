# LiveStudio Social — わんコメ用プラグイン

[わんコメ](https://onecomme.com/) のコメントと投げ銭を、`jp.lilium.livestudio.social` を組み込んだ LiveStudio アプリへ転送します。コメントでデッキの操作を発火できるようになります。

わんコメが対応しているプラットフォーム（YouTube / Twitch / ニコ生 / ツイキャス / KICK ほか）をこれ 1 本でカバーします。わんコメが正規化済みのコメントを読むだけなので、LiveStudio 側は各プラットフォームの API を一切知りません。

---

## 動作条件

- わんコメ **5.2** 以降（プラグイン機構が入ったバージョン）
- 同じ PC で動いている LiveStudio アプリ。シーンに **Social** ゲートウェイが置かれていること

## 導入

1. わんコメの右上メニュー →**プラグイン** を開き、**プラグインフォルダ** を押します。Windows では `C:\Users\<ユーザー名>\AppData\Roaming\onecomme\plugins\` が開きます。
2. `onecomme-plugin` フォルダごとその中にコピーします。`plugin.js` が 1 階層下にある状態、つまり `…\plugins\onecomme-plugin\plugin.js` になるようにしてください。
3. プラグインウィンドウで **再読み込み** を押すと、一覧に *LiveStudio Social* が現れます。
4. トグルで有効化します。

## 設定

一覧の項目から設定ページを開きます。

| 設定 | 入れるもの |
|---|---|
| **ポート** | LiveStudio アプリの **Social** ページに表示されている番号（通常の Studio アプリなら 3003）。 |
| **トークン** | アプリ側で設定したときだけ入力します。設定していなければ空欄のままで構いません。 |

届かないときはアプリの **Social** ページを見てください。コメントが届いた瞬間に *Events Received* が増えます。増えない場合はポート違いか、アプリ側にトークンが設定されているのにプラグイン側が空欄、のどちらかがほとんどです。

## 送られる内容

コメント 1 件が LiveStudio のイベント 1 件になります。わんコメのプラットフォーム ID はそのまま渡しますが、LiveStudio と綴りが違う 2 つだけ読み替えます（`niconama` → `niconico`、`twicas` → `twitcasting`）。

| わんコメ | LiveStudio の `type` |
|---|---|
| 通常のコメント（`hasGift` が false） | `chat` |
| YouTube スーパーチャット | `superchat` |
| YouTube スーパーステッカー | `sticker` |
| YouTube 新規メンバー / メンバー継続メッセージ | `membership` |
| YouTube メンバーギフト（贈った / 受け取った） | `gift` |
| Twitch チア（ビッツ） | `cheer` |
| その他のギフト | `gift` |

`amount` に金額（チアの場合はビッツ数）、`currency` にその単位がプラットフォームの申告どおり入ります。換算はしません。モデレーター・メンバー・配信者のフラグも渡るので、「メンバーだけ」「モデレーターだけ」といった条件を LiveStudio 側で指定できます。`isMember` は YouTube のメンバーフラグと Twitch のサブスクライバーフラグから取ります。

コメントはまとめて届くので 1 リクエストで送ります。直近の ID を覚えているため、再送されても操作が二重に発火することはありません。

## クレジット表記

わんコメの利用規約では、**無料版**を使う場合に配信の概要欄などへクレジットを記載するようお願いされています（PRO 版では任意）。次のような記載で足ります。

```
コメント表示: わんコメ https://onecomme.com/
```

これはこのプラグインではなく、わんコメ本体を使うことに対する規約です。配信側に記載してください。
